# 07 · 回读自检

## 1. 职责

不信生成时的自述，**重新打开成品 docx** 按契约逐项核对（54 项）：

```text
契约/口径（章节契约、表格契约、财务口径）+ 成品 docx + 过程 JSON → 自检.json（cardo/invest-check/v1）
```

## 2. 输入 / 输出

| 方向 | 路径 |
|---|---|
| 读 | `…/04_成果报告/*建议书*.docx`（重开回读） |
| 读 | `…/05_过程/投资决策/财务测算.json`（数字对账） |
| 读 | `规则/章节契约.yaml`、`规则/表格契约.yaml`、`规则/财务口径.yaml` |
| 读 | `..\提资数据\模板\建议书模板.docx`（sha 与契约登记比对） |
| 写 | `过程文件/07-回读自检/自检.json` |

## 3. 命令

```powershell
python Skills/07-回读自检/scripts/check_invest.py `
  --project-dir 过程文件/00-总控/引擎项目 `
  --format json --out 过程文件/07-回读自检/自检.json --no-timestamp
```

退出码：`0` 全过；`1` 有失败项；`2` 项目已给但找不到成品 docx（输入缺失）。

## 4. 检查分组

| 组 | 关键项 | 门槛 |
|---|---|---|
| 契约 CH-* / PR-* / GA-* | 10 章、40 小节、34 条模板提示行全转规则、8 条全局断言 | 全 true |
| 表格契约 TB-* / 资产 ASSET-* | 表位 1–6 形状、表头、键、模板 sha | 全 true |
| 财务口径 FIN-* | 计算期/折现率与输入一致（本项目 3+29=32 年、2.7%）、8 个锚点、10 项指标、反作弊声明 | 全 true；原始模板缺失时 FIN-SOURCE 降级 skip 并显式登记 |
| 成品 DOC-* | 章数/章序/表位数/表头/"数据来源"残留/占位符/盘符/项目名与工作区参数一致 | 全 true |
| 数字 NUM-* | 表位 1/2 数字 = 可研口径指标（`财务输入#finance.referenceIndicators`，有则优先）或财务测算.json；表位 3/5/6 矩阵互反、权重合计≈1 | 全 true |
| 断言 ASSERT-MAP | fail 级断言均有实现 | 全 true |

## 5. 数字容差（成品口径）

`FIRR 0.04pp` / `FNPV 0.01 万元` / `回收期 0.01 年`。

## 6. 定位的两类真实风险

1. **数字对不上**：只改 docx 不改 JSON，或反过来 → NUM-MATCH 失败；正确做法是重跑 03→06。
2. **章序/表头被改**：DOC-CHAPTER-ORDER / DOC-TABLE-HEADER 失败；不许手工"调整"契约结构。

- 新增/调整检查项：改 `check_invest.py`（与 06 渲染互不影响）；
- 契约阈值：改 `规则/表格契约.yaml`、`规则/章节契约.yaml`（版本 +1 + 全链回归）；
- 原始模板对账为可选：未提供原始模板时 FIN-SOURCE 自动降级为 skip（仍校验 8 个写死锚点），不影响交付。
