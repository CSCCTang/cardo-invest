# 常见失败（cardo-invest）

| 看到的提示 | 怎么办 |
|---|---|
| 找不到财务参数 | 把 `财务参数.xlsx` 放进 `输入文件\` |
| 工程费表为空 / 缺金额列 | 按样例补「名称 + 金额(万元)」两列 |
| 缺规划依据口径 | 在 `工作区参数.json` 填 `narrative.planningBasis` |
| 工作区已有上一次产物 | 换一个新的空工作区重跑 |
| PDF 未生成 | 先确认本机 Word 可用；或把 docx 另存为 PDF |
| 依据条目与项目所在地不符 | 按 `docs/02_输入准备.md` 替换依据库后重跑 |
