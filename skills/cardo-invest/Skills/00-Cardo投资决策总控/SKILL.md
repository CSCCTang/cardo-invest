# 00 · Cardo投资决策总控（唯一入口）

本技能只做编排：按顺序调用编号技能，每步跑完过闸门，不通过即停并说明原因。
中间产物落 `过程文件/<编号-名称>/`，成果只落 `成果文件/`（Office）。

## 执行原则

1. **按 skill 顺序一步一步来**：00 总控 → 01 取料 → 02 匡算 → 03 财务评价 → 04 三方案比选 →
   05-00 分章引擎 → 05-01…05-10 十个章节 skill → 06 渲染 → 07 回读 → 08 独立验证。
2. **每步四件事**：读上一步产物 → 执行本步命令 → 核对闸门 → 写留痕；不通过就停在这一步。
3. **报告是“写”出来的，不是“拼”出来的**：05 逐章写、06 逐章回读渲染、07/08 逐项对账。
4. **不补数、不编造**：缺什么就登记缺口并在对话里说明替代方案。

## 输入投递（不分类、不限层级）

`输入文件/` 是投递区：用户可以直接放**文件、文件夹或 zip 压缩包**，总控会用
`01-上游取料` 递归发现并按文件名关键词归类（`现状分析报告`、`AHP权重表`、`AHP方案评分结论`、
`低空现状指标`、`槽位`、`财务参数`），zip 自动解包到
`过程文件/00-总控/输入解包/`。

发现缺件时，总控**在对话里逐条说明**，并给出可选方案（示例）：

| 缺什么 | 对话提示（含替代方案） |
|---|---|
| 现状分析报告 | 手上有 CardoStatus 产出的《现状分析报告》就放进 输入文件/；没有则跳过，第 1—6 章按缺口版出稿并逐条标注 |
| AHP 三件套 | 手上有 CardoAHP 产出的权重与评分就放进 输入文件/；没有则用默认权重并标 temporary，不编造专家评分 |
| 低空现状指标 | 从 CardoOSGB 的 `过程文件/06-2.5D网格指标/` 复制 `现状指标.json` 到 `输入文件/`；只有 xlsx 不行——留档但不消费，第 3 章少一张指标表 |
| 槽位 | 请项目负责人填写；暂缺时登记缺口并在正文写「资料缺失」，不按经验推定 |
| 财务参数 | **唯一必需输入**：按估算附表填工程费/其他费/收入/成本/资金结构；缺失则停下等补齐，不补数 |

模板与标准件**不属于用户输入**：统一放根目录 `提资数据/模板/`，本工作区只引用相对路径。

## 一键执行

```powershell
python Skills/00-Cardo投资决策总控/scripts/pipeline.py status --workspace .
python Skills/00-Cardo投资决策总控/scripts/pipeline.py run    --workspace .
python Skills/00-Cardo投资决策总控/scripts/pipeline.py run    --workspace . --from 05
python Skills/00-Cardo投资决策总控/scripts/pipeline.py run    --workspace . --scenario gaps --baseline none
```

退出码：`0` 全过；`1` 某步失败；`2` 参数/工作区/前置产物问题。

## 逐步操作卡

### 00 预备：确认工作区与输入
- 读 `工作区参数.json`（`paths.inputRoot / upstreamJson / financialParams / template / stagingProject`）。
- 核对 `输入文件/` 是否至少有一份 `财务参数.xlsx`；没有就直接问用户。
- 核对根目录模板 `../提资数据/模板/建议书模板.docx` 是否存在、sha 是否与章节契约一致。

### 01 上游取料（`01-上游取料`）
- 执行：`python Skills/01-上游取料/scripts/prepare_inputs.py --workspace .`
- 产物：`过程文件/01-上游取料/取料清单.json`、`缺项表.md`；引擎项目装配到 `过程文件/00-总控/引擎项目/`。
- 闸门：gaps 四要素（code/what/need/suggestion）齐全；AHP 缺失必须标 temporary；财务参数缺失 exit 3。
- 失败：把 `missing[]` 逐条念给用户，给出上表替代方案，等补齐或拍板缺口版。

### 02 匡算（`02-匡算`）
- 产物：`投资估算.json`。
- 闸门：总投资非空；分项可加总；资金筹措与总投资差 ≤1 万元。

### 03 财务评价（`03-财务评价`）
- 产物：`财务测算.json`、`计算轨迹.json`。
- 闸门：10 项指标齐全；现金流存在；指标必须由现金流算出。

### 04 三方案比选（`04-三方案比选`）
- 产物：`方案比选.json`、`方案对比表.md`。
- 闸门：3 套方案、id 唯一、有推荐结论与权重来源。

### 05-00 分章引擎（`05-章节成文`）
- 执行：`assemble_chapters.py --project-dir 过程文件/00-总控/引擎项目`
- 产物：`05_过程/投资决策/分章/CH-01..CH-10.md`、`来源映射.json`、`缺项表.md`。
- 闸门：10 章齐全非空、章序正确、来源映射 ≥10 条。

### 05-01…05-10 章节 skill（逐章复核）
按顺序执行，**一章不过不进下一章**：

| 章 | skill | 契约 |
|---|---|---|
| CH-01 | `05-01-项目概述` | 规则/章节契约.yaml |
| CH-02 | `05-02-项目背景与建设必要性` | 同上 |
| CH-03 | `05-03-现状调研分析` | 同上 |
| CH-04 | `05-04-市场分析与功能定位` | 同上 |
| CH-05 | `05-05-项目建设范围、改造内容与建设方案` | 同上 |
| CH-06 | `05-06-组织架构与运营模式` | 同上 |
| CH-07 | `05-07-投资估算与资金筹措方案` | 同上 |
| CH-08 | `05-08-财务评价` | 同上 |
| CH-09 | `05-09-基于AHP层次分析法的投资决策指标体系量化分析` | 同上 |
| CH-10 | `05-10-附件清单` | 同上 |

- 每章执行：`python Skills/05-章节成文/scripts/check_chapter.py --project-dir 过程文件/00-总控/引擎项目 --chapter CH-0X --out 过程文件/05-章节成文/分章自检/CH-0X.json`
- 闸门：H1 逐字、H2 ≥1、每节有 `来源：…`、占位已登记、字数达 80%。

### 06 渲染 docx（`06-渲染docx`）
- 模板：`../提资数据/模板/建议书模板.docx`（唯一副本，不在输入区）。
- 产物：`成果文件/成品版/项目投资决策建议书/项目投资决策建议书.docx` 与同名 `.pdf`、`自检-渲染.json`。
- 闸门：章 10 / 表位齐全 / 占位符 0 / 无「数据来源」残留 / 渲染自检 pass / 成品 PDF 已生成。

### 07 回读自检（`07-回读自检`）
- 执行：`check_invest.py --project-dir 过程文件/00-总控/引擎项目`
- 闸门：54 项 0 失败（章序、表头、数字对账、断链、模板 sha）。

### 08 验证与边界（`08-验证与边界`）
- 产物：`成果文件/内部件/{投资估算,财务评价,方案比选,依据对照表}/<同名>.xlsx`、`独立验证结果.json`、`产物指纹.json`、`成品闸门报告.json`。
- 闸门：独立复算 0 失败；输入/成果扩展名白名单 0 违规；过程产物无盘符路径；成品闸门五道全过
  （交付结构、封面不印页码/页脚页码/目录页码、成品零缺口词、三源同源、政策文号有据）。

## 常见问题
- **01 exit 3**：`财务参数.xlsx` 缺失或表「工程费」读不到编号/名称/金额 → 补齐重跑，不补数。
- **05 某章失败**：停在该章，按 `分章自检/CH-0X.json` 的 FAIL 项改契约取数或登记缺项，禁止跳过。
- **06 缺模板**：确认 `提资数据/模板/建议书模板.docx` 存在且 sha 与契约一致。
- **07 NUM-MATCH**：过程 JSON 与成品数字不一致（被手改过）→ 重跑 02→06，禁止直接改 docx。
- **08 基线失败**：口径变更后显式重写 `记忆与规则/验证基线-CardoInvest.json`（`--baseline write`）。
