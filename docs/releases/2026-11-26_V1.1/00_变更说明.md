## 一、这一版改了什么

### 1. 去 AI 味改写规则

**改了什么**

- `Skills\05-章节成文\规则\写作规范.yaml` 新增 `deaiRules`：必删 B1—B12 的判据、慎用 C 类的定位规则，与 `04_工具与方法论\01_技能\08_去AI味` 同源。
- 2.3「现存主要问题」重写：把上游原文的「（1）表现：…（2）证据：…」提纲编号去掉，按「现状—依据—成因—影响—更新方向」并成自然段。
- 措辞修正：2.4「直接抓手」改为「落到具体工程上」；1.4、8.3 去掉「进一步」。
- `Skills\08-验证与边界\scripts\` 新增 `deai_scan.py`（随包自带扫描器）与 `deai_gate.py`（成品闸门）。
- `Skills\00-Cardo投资决策总控\scripts\pipeline.py` 第 08 步调用 `deai_gate.py`：成品 docx 必删清零才放行，分数与四项指标留痕。

**为什么**

交付正本的语言体检测出必删 2 处、总分 37（C）。规则写在文档里但流水线不执行，等于没写。本版把判据变成脚本闸门。

**影响哪些页**

2.3、2.4、8.3 三节文字；1.4 一处措辞。两版均为 45 页（新版基线表格 26 张，比旧交付基线少 5 张，页数由 50 降到 45）。

### 2. 数字溯源

**改了什么**

- 新增 `Skills\08-验证与边界\scripts\export_trace_sample.py`，第 08 步生成内部件 `成果文件\内部件\数字溯源表\数字溯源抽样.md`。
- 口径分两级：值级（数值绑到上游 JSON 唯一字段）、段级（数值未绑字段但整段有来源行）。两级都能回到原始文件。

**为什么**

原来 `依据对照表.json` 只有「值级 / 未定位」两档，「未定位」读起来像无出处。实际上每个段落都有来源行，只是没绑到唯一字段。新增段级口径后，无出处的数字为 0。

**影响哪些页**

不改正文，只多一份内部件。

### 3. 按项目负责人工作流的叙述顺序

**改了什么**

- `写作规范.yaml` 新增 `narrativeOrder`：每节按「谁在做 → 原来怎么干 → 现在怎么干 → 省掉或新增 → 还差什么」组织。
- 2.3 的「现状—依据—成因—影响—更新方向」是这条顺序在问题描述上的落地。

**为什么**

原稿多处先讲指标和工具，读者看不到人怎么干活。把叙述顺序写成规则，避免下一轮又回到「随着…背景」开篇。

**影响哪些页**

2.3、2.4 的段落结构；6.1、6.2 本就按「谁在做／收益构成」写，只登记规则，不改文字。

### 4. 目录与命名规范

**改了什么**

- 新版包放在 `05_归档\03_封版包\04_2026-11-26_Invest_V1.1\CardoInvest\`，沿用「NN_YYYY-MM-DD_事项」。
- 包内结构与正本一致，不新增顶层目录；新增脚本只进 `Skills\08-验证与边界\scripts\`。
- 领导版成果、变更说明、自检记录按三组分目录，组内平铺。

**为什么**

包版本与汇报材料分开放，正本不动，新版可追溯。

**影响哪些页**

不影响正文。

## 二、没有并入的内容
