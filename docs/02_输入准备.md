# 输入准备（cardo-invest）

## 文件清单

| 文件 | 必需 | 形态与要求 |
|---|---|---|
| `财务参数.xlsx` | 是 | 「工程费」表至少 1 行：名称 + 金额(万元) |
| `工作区参数.json` | 是 | 至少填 `narrative.planningBasis`；首次运行自动生成骨架 |
| `槽位.xlsx` | 否 | 列名与样例一致即可 |
| 上游产物 | 否 | 现状指标 / 事实库 / AHP 结果，放 `输入文件\` 任意层级 |

## 最小样例

- `skills\cardo-invest\assets\inputs\财务参数-空白.xlsx`
- `skills\cardo-invest\assets\inputs\槽位-空白.xlsx`

## 依据库

- 位置：`skills\cardo-invest\assets\依据库\`（以四川为样本，含省/市条目）。
- 替换方法：把你项目所在地的法规、标准、规划条目按同样字段追加进去；
  字段含义见同目录说明。替换后结论会引用你所在地的依据。

## 摆放

```
D:\proj\invest-01\
  输入文件\财务参数.xlsx
  工作区参数.json
```

## 不要放什么

- 多个版本的财务参数（先定稿一份）。
- 含公式引用外部文件的 xlsx（请另存为数值）。

## 口径

- `narrative.planningBasis` 等委托方裁定项留空时，正文用中性表述，不替使用者下结论。
