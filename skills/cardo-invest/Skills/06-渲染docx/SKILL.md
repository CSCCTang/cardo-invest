# 06 · 渲染 docx

## 1. 职责

以建议书模板（根目录 `..\提资数据\模板\建议书模板.docx`，经 `--template` 传入）为基底重建正文与 6 张表，输出可交付 docx：

```text
分章/CH-01..10.md + 财务输入/投资估算/财务测算.json + 模板 → 04_成果报告/项目投资决策建议书-<项目>.docx + .自检.json
```

## 2. 输入 / 输出

| 方向 | 路径 |
|---|---|
| 读 | `…/05_过程/投资决策/分章/CH-*.md`、`财务输入.json`、`投资估算.json`、`财务测算.json`、`AHP/权重表.json` |
| 读 | `..\提资数据\模板\建议书模板.docx`（**必须**用 `--template` 传入；技能与输入区都不放模板原件） |
| 写 | `…/04_成果报告/项目投资决策建议书-<项目>.docx` + 同名 `.自检.json` |
| 写（总控复制） | `成果文件/成品版/项目投资决策建议书/项目投资决策建议书.docx` 与同名 `.pdf`、`过程文件/06-渲染docx/自检-渲染.json` |
| 写（内部件） | `成果文件/内部件/依据对照表/依据对照表_投资建议书.xlsx` |

## 3. 命令

```powershell
python Skills/06-渲染docx/scripts/build_invest_docx.py `
  --project-dir 过程文件/00-总控/引擎项目 `
  --template ..\提资数据\模板\建议书模板.docx --no-timestamp
```

退出码：`0` 成功且自检 pass；`1` 自检 fail；`2` 输入/模板缺失。

## 4. 表图（35 张表 + 8 张图）

| 类别 | 位置 | 说明 |
|---|---|---|
| 表位 1–6 | 第 8/9 章 | 全部投资指标、资本金指标、准则矩阵、指标层四组矩阵、准则权重、综合权重 |
| 其余分析表 | 各章就地 | 由 05 以“表 <章>-<序> 题注 + Markdown 管道表”输出，06 统一渲染为 Word 表 |
| 必备图 | 3-1/3-2/5-1/6-1/8-1/8-2/9-1/9-2 | 05 输出“图 <章>-<序> 题注”，06 调用 `figures.py`（PIL，无 numpy/matplotlib 依赖）绘图并嵌入；3-1 读 `输入文件/03-OSGB成果` 的正射/地类/轮廓，缺件不画 |

表号/图号按成品出现顺序连续，不按模板索引跳号；07/08 按表头定位表位，不按 docx 表索引取第 N 张。

## 5. 闸门（渲染自检 `.自检.json`）

1. `chapters.count = 10` 且标题与契约一致；
2. `tables.count ≥ 20` 且表位 1–6 按表头全部命中；
3. `figures.count ≥ 8`；
4. `placeholders = []`（`{{…}}`/TODO/XXX 0 残留）；
5. `residue = false`（成品无"数据来源"字样）；
6. `result = pass`，否则 build 退出码 1，总控即停。

## 6. 规则

1. 模板只做基底：只搬样式/页面设置/章节骨架，不复制模板坏公式与错误单元格；
2. 数字只有一个来源：表 1/2 从 `财务测算.json#indicators` 取，不二次计算；
3. 缺项显式：保留"（资料缺失，见缺项表）"，不补数、不隐藏；
4. **不生成即交付**：必须由 07 回读自检通过才算完成。
5. **标题编号**：模板 Heading 1–9 样式自带 `numId=1`（“第%1章 ”“%1.%2”），渲染前调用 `strip_heading_numbering()`
   移除样式级/段落级 `numPr`，成品只保留分章稿手写的“1.1”编号，避免 Word 显示“第一章 1 项目概述”。
6. **来源行**：分章稿每节末尾的“来源：…”只用于来源映射，`add_markdown()` 跳过该行，成品正文不出现机读溯源行。
7. **表图题注**：题注居中、不加首行缩进，表头加粗；07/08 以表头文本匹配表位，题注编号不参与校验。
8. **正文版式**：Normal 样式统一 1.5 倍行距、首行缩进 0.74 cm；Markdown 空行不生成空段落，避免正文稀疏。
9. **封面**：项目名 → Title → 编制日期 → 分页；封面段落用 Normal 样式，不能用 Heading（否则章数变 11）。

## 7. 调优点

- 版式/字号/表格样式：改 `build_invest_docx.py`（每个技能自包含，互不影响）；
- 模板：替换 `..\提资数据\模板\建议书模板.docx`；替换后需同步更新 `05/07 规则/章节契约.yaml` 的 `templateSha256`，
  否则 07 的 `ASSET-SHA` 会失败（这是有意的模板锁）。
