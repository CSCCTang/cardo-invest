# 使用流程（cardo-invest）

## 从哪进

在 dsh 对话里说一句：

> 用 cardo-invest 跑，工作区是 `D:\proj\invest-01`

工作区用独立空文件夹；建议每次跑新目录。

## 给什么

1. `输入文件\财务参数.xlsx`（「工程费」表至少 1 行：名称 + 金额(万元)）。
2. `工作区参数.json`：首次运行会生成骨架，至少填 `narrative.planningBasis`（委托方裁定口径）。
3. 可选：`输入文件\槽位.xlsx`；上游产物（现状指标 / 事实库 / AHP 结果）放 `输入文件\` 任意层级。

## 拿到什么

`成果文件\`：

- 《项目投资决策建议书》docx + PDF
- 投资估算表（xlsx）
- 财务评价表（xlsx）

## 备注

- 依据库以四川为样本，使用者按项目所在地替换（方法见 `docs/02_输入准备.md`）。
- 委托方口径未填时，报告用中性表述，不替使用者下结论。
