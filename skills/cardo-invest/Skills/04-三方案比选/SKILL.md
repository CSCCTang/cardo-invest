# 04 · 三方案比选

## 1. 职责

按三类模式生成 **3 套候选方案**（拆除重建 / 微更新 / 功能置换），给出成本收益对比与推荐结论：

| 模式 | 成本特征 | 收益特征 |
|---|---|---|
| 拆除重建 | 高投入、长周期 | 新增载体租赁/销售 |
| 微更新 | 低投入、短周期 | 租金提升 + 运营收入 |
| 功能置换 | 中投入 | 业态升级后的租金/运营 |

## 2. 输入 / 输出

| 方向 | 路径 | 用途 |
|---|---|---|
| 读 | `…/05_过程/投资决策/财务输入.json` | 折现率、方案参数、AHP 权重 |
| 读 | `…/05_过程/投资决策/投资估算.json` | 匡算基数（总投资） |
| 读 | `…/05_过程/投资决策/财务测算.json` | 基准收入/成本/指标/计算期 |
| 读（可选） | `05_过程/AHP/权重表.json` | 准则权重（缺失用默认，标 temporary） |
| 读 | `规则/方案参数表.yaml`、`规则/财务口径.yaml` | 方案系数、默认权重、期数兜底 |
| 写 | `…/05_过程/投资决策/方案比选.json` | `cardo/scheme-compare/v1` |
| 写 | `…/05_过程/投资决策/方案对比表.md` | 人读对比表 |
| 写（总控复制） | `过程文件/04-三方案比选/` | 供 05/08 消费 |

产物核心块：`schemes[]`、`compare`、`winner`、`compareTable{columns[], rows[], recommendation, runnerUp, base, caliberNote}`。

## 3. 命令

```powershell
python Skills/04-三方案比选/scripts/gen_schemes.py --project-dir 过程文件/00-总控/引擎项目 [--params <参数.json>] [--no-timestamp]
```

退出码：`0` 生成 3 套；`1` 参数校验失败（不足 3 套/模式重复）；`2` 输入缺失；`3` 方案关键参数缺口（产物仍落盘）。

## 4. 闸门

1. 恰好 3 套、id 唯一、模式不重复；
2. 7 个比较维度齐全：总投资、资本金投入、FIRR、FNPV、静态回收期、补贴依赖度、实施周期；
3. 有 `recommendation.winner` 与 `weightsSource`（`ahp` / `ahp-temporary` / `default`）；
4. AHP 缺失时 `temporary=true`，并在对比表标注"待 AHP 输出替换"。

## 5. 规则

1. **同源同口径**：三方案用同一套参数缩放与简化现金流，不各算一套；
2. **不重算 AHP**：权重只读上游/默认，不做一致性检验；
3. **口径隔离**：方案指标为参数缩放口径，与第 7 章投资估算不同源；产物内 `caliberNote`/`note`/对比表 md 三处标注；
4. **不编造**：某方案关键参数不全 → 该方案 status=gap，不借用其他方案数字；
5. **结论回写**：`compareTable.recommendation` 供第 9 章直接引用。

## 6. 调优点

- 方案系数/默认权重/必需参数清单：改 `规则/方案参数表.yaml`；
- 方案数量或模式：属口径变更，需改 `gen_schemes.py` 并升版本、全链回归。
