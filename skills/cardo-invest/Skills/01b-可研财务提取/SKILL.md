# 01b · 可研财务提取

## 0. 能收到什么材料，不够时怎么补

本技能只做一件事：**从收到的材料里提取财务数据，写进 `输入文件/财务参数.xlsx`**。

### 收料与补充（级联，逐级往下）

```text
第 1 级：成果文件里的匡算/财务评价工作簿（*.xlsx）
         附表1 工程总投资估算表 / 附表3 资金筹措表 / 附表4 收入表 /
         附表5 总成本费用表 / 附表7 借款还本付息表 / B0 建设内容与规模表
         → 结构化表格，最完整，**优先用**

第 2 级：可研 PDF（*可研*.pdf / *可行性研究报告*.pdf / *项目建议书*.pdf）
         → 用坐标+表格识别抽投资估算附表与正文结论（工程费用、预备费率、
           资金来源、项目名称/方向/面积）
         → **PDF 抽不动时，用第 1 级补**（反之亦然，两级合并）

第 3 级：仍缺的 → **留空**，登记缺项，等用户补
         → 空着是正常状态，不是缺陷；绝不用经验值/推算值代替
```

各项目的材料形态不同（实测：老旧厂区的可研只有 PDF，成果文件在别的目录；
老旧街区的项目有 58 表的匡算工作簿；东部新区是 10 表的另一套结构），
所以识别一律**按内容特征**（表头文字），不按文件名。

### 判断标准

「够用能跑」即可 —— 让 02 匡算能算出总投资、03 能跑完财务评价。
不追求逐项完美还原；只抽到大类值的项目（如某市某片区）是合格产出。

## 1. 职责

把「提资材料里的可研/估算文件」变成 `输入文件/财务参数.xlsx`（9 张表），
让用户**不必手工从 PDF 抄数**，同时保持「只收不猜」：

```text
输入文件/（可研 PDF / 投资估算 xlsx）
  → 投资估算附表解析（工程费 / 其他费 / 预备费 / 总投资）
  → 可研正文解析（项目名称/方向、经济指标、资金来源、预备费率）
  → 输入文件/财务参数.xlsx（9 张表 + 出处台账 + 填写说明）
  → 过程文件/01b-可研财务提取/预填台账.json
```

**关键约束**：

1. **财务参数.xlsx 始终在 `输入文件/`** —— 它是 01 取料唯一认的路径，
   不是过程文件。用户填过的格子**不会被覆盖**（可重复运行，逐步补全）。
2. **每个数字带出处**：来源文件 / 页码或工作表 / 行号 / 原文片段，
   全部登记在 `出处台账` 工作表与 `预填台账.json`。
3. **抽不到就留空**：不填行业经验值、不引用相似项目数字、不外推。
   留空 = 「材料中尚未找到该数」，由 01 取料登记进缺项表。
4. **平衡自检**：工程费 + 其他费 + 预备费 + 建设期利息 vs 总投资，
   差 ≤1 万元才算通过；不通过要显式报警（不静默算错）。

## 2. 输入 / 输出

| 方向 | 路径 | 说明 |
|---|---|---|
| 读 | `输入文件/**/*可研*.pdf`、`*可行性研究报告*.pdf`、`*项目建议书*.pdf` | 项目级可研 |
| 读 | `输入文件/**/*匡算*.xlsx`、`*投资估算*.xlsx`、`*附表*.xlsx` | 估算类工作簿（附表形态） |
| 写 | `输入文件/财务参数.xlsx` | **9 张表 + 出处台账 + 填写说明**（原地补全） |
| 写 | `输入文件/财务参数-空白.xlsx` | 从技能包 `assets/inputs/` 释放，用户可填 |
| 写 | `过程文件/01b-可研财务提取/预填台账.json` | 机读台账 |

**批量倒推的落位规则**（`backfill_projects.py`）：

| 情形 | 落位 |
|---|---|
| 可研所在目录已有「输入」/「成果」子目录 | 该项目目录的 `输入/财务参数.xlsx` |
| 可研在项目目录的子层（如 `输入/某路/xxx.pdf`） | 向上找到的项目目录的 `输入/` |
| 可研直接在分类目录下（如 `老旧厂区/2-1.某企业饮品老旧厂区可研.pdf`） | 新建 `<可研名>/输入/财务参数.xlsx` |
| 同一项目目录下有多份可研（附件版/附图版） | **只取一份**（正文报告优先），落到同一 `输入/`，不造「（2）」目录 |
| 项目没有可研 | 只放 `财务参数-空白.xlsx`，等用户填 |

绝不创建「（2）」「（3）」这类项目目录 —— 一个项目一个目录，目录里只有 `输入/` 与提资方自己的材料。

9 张表：项目 / 工程费 / 其他费 / 预备费 / 建设期利息 / 收入 / 成本 / 资金结构 / 可研财务指标。

## 3. 命令

```powershell
# 工作区根
python Skills/01b-可研财务提取/scripts/build_params.py --workspace .
python Skills/01b-可研财务提取/scripts/build_params.py --workspace . --dry-run

# 批量倒推各项目（把提资数据里每个可研跑一遍，产出各项目的 财务参数.xlsx）
python Skills/01b-可研财务提取/scripts/backfill_projects.py --source <提资数据根>
```

退出码：`0` 完成；`2` 未找到可解析财务源（保留空白模板，等用户补料）。

## 4. 闸门

1. 产出 `输入文件/财务参数.xlsx` 且含 9 张表（缺表补空表，避免 01 取料报结构不可用）；
2. 平衡自检：明细合计与表列总投资差 ≤1 万元，否则记 warning 并继续（由 01→08 决定是否放行）；
3. 每个写入的数字在 `出处台账` 有对应行（无出处的值不写）；
4. 用户已填的格子不被覆盖。

## 5. 规则

1. **只收不猜**：抽不到留空；不用经验值、不外推、不跨项目借数。
2. **出处可追**：出处台账四要素齐全（文件 / 页码或工作表 / 行号 / 原文片段）。
3. **表结构自适配**：附表列序各可研不同（某可研「建筑工程费|设备购置及安装|其他费用|合计」
   vs 另一份「建筑工程|安装工程|设备及工器具购置|其它费用|合计」），
   一律**按表头文字定位列**，不写死列号。
4. **层级用附表自身**：父级金额 = 子项之和，故取「分组层」（如「（一）基础设施改造」）
   作为明细，数字层（1/1.1/1.2.1）丢弃；没有分组层时取最浅的数字层。
5. **资金来源不混**：附表里的百分数是**占比**不是费率，预备费率用
   「预备费 ÷（工程费+其他费）」反算；正文「基本预备费…计 X%」只作对照。

## 6. 已知限制（实测）

| 情况 | 表现 | 处置 |
|---|---|---|
| 可研只给「投资构成汇总表」（工程费用/其他费/预备费/总投资四行），明细在别处或没有 | 明细行数 0 | 用大类值兜底进「工程费/其他费」表，出处写明是汇总行 |
| 投资估算附表是图片（无文本层） | 抽不到任何数 | 留空 + 登记缺项，提示用户填 |
| 可研完全无财务附表（仅正文结论句） | 抽到总投资与三个大类 | 明细留空 |
| 序号的小数点被 PDF 抽取吃掉（`1.2.1`→`121`） | 层级判断退化 | 按「位数=层级」判父子；金额自洽校验兜底 |
